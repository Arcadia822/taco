# 大规模 Checkpoint 滚动示例

这是存放在 `examples/` 下、用于检验 Checkpoints 页面横向与纵向滚动及连线位置的演示数据；不随 Taco skill 或 Spec Kit extension 作为模板发布，也不是待交付的真实项目规范。

- 10 个依赖层，每层 5 条并行工作流，共 50 个 Checkpoint。
- 每个节点引用 4 份文档，共 200 条文档要求；部分文件已创建，其余保留为未创建占位行。
- 第一层为示例冻结状态，第二层混合进行中和已完成，其余默认待开始。状态仅为演示数据，不表示真实审批。
- 桌面上打开 Checkpoints 入口，左右及上下滚动；窄屏改为单列堆叠，不绘制连线。

`bundle.json` 是滚动演示的数据源，`empty.taco.html` 是可直接打开的展示文件。不要从这个目录为真实项目复制 Checkpoint 图或状态；实际项目应依据自己的评审约定建立它们。
