## 总览

Taco 由四部分组成：一个自带应用的 HTML 文件、浏览器里的运行时、一份文件协议，以及可选的宿主。组件关系见 [系统组件图](系统组件.mmd)。

## 一个文件 = shell + 数据块

- **shell**：压缩内嵌的应用（阅读器、编辑器、评论、导航），所有 Taco 都相同；
- **数据块**：`<script type="application/taco+json" id="taco-document">` 里的一段 JSON，装着这个议题的全部文档和评审状态。

Agent 只写数据块，从不改动 shell，所以升级应用和更新内容互不干扰。

| shell | 体积 | 依赖 |
| --- | --- | --- |
| Complete | 约 2.7 MB | 全部内嵌，完全离线 |
| Lite | 约 180 KB | 启动时从公共 CDN 加载编辑器 |

## 数据块：taco/files v1

| 字段 | 说明 |
| --- | --- |
| `docId` | 文档身份，首次生成后每次刷新都保留 |
| `files[]` | 每个文件的路径、类型、内容和打包时的 `sourceHash` |
| `comments[]` | 评论线程：锚点、状态、消息 |
| `navigation` | 可选：入口文档与分组 |
| `checkpoints` | 可选：阶段图与文档状态 |

刷新时保留 `docId`、评论、导航和检查点，这就是「同一个 Taco」能跨轮次延续的原因。

## 往返与冲突

1. 打包时每个文件记录内容哈希（`sourceHash`），代表评审者看到的版本；
2. 「交接改动」输出改动 diff 和未解决的评论；
3. Agent 应用前对照哈希检查源文件：打包后被改过、或 diff 无法干净应用，就报告冲突并停下，不覆盖任何一方。

## 安全

- 文件路径必须在文档目录之内，越界即拒绝；
- 普通 `.html` 源文件不能打包进 Taco；
- 启用在线协作的 Taco 可能带有访问凭据，不要随意转发。

## 宿主

- **本地**：直接用 `file://` 打开，不需要任何服务；
- **Tacobin**：负责发布、自动保存、在线状态和交接事件，主要接口见 [Tacobin API](Tacobin-API.yaml)。
