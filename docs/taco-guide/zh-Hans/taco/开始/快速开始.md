title: 快速开始
status: 已完成
time: 约 5 分钟
---

## 1. 让 Agent 安装 Taco

把下面这句话发给你正在用的 Agent（Claude Code、Codex、Cursor 等）：

```text
阅读 https://github.com/Arcadia822/taco/blob/main/docs/agent-installation.md ，按其中步骤为我安装 Taco；安装完成后，向我介绍 Taco 怎么用。
```

Agent 会安装 `taco` skill。这就是完整安装：不需要 npm 包、CLI 或构建步骤，之后完全可以离线使用。

也可以自己执行：

```bash
npx skills@latest add arcadia822/taco --skill=taco
```

## 2. 让 Agent 写一份方案，并生成 Taco

```text
为「订单导出 CSV」写一份设计方案（需求、方案、接口），放在 specs/order-export/，用 Taco 给我评审。
```

Agent 写好 Markdown 后，会把整个目录打包成 `specs/order-export/order-export.taco.html`，并在浏览器里打开它。

## 3. 在浏览器里评审

- 选中一句话，点「评论」，写下具体意见；
- 发现错字或措辞问题，直接在正文里改；
- 流程图节点、代码块的某一行也可以评论。

## 4. 交接给 Agent

点右上角「交接改动」，改动的 diff 和未解决的评论会复制到剪贴板。粘贴给 Agent 即可。

## 5. 核对第二轮

Agent 改完源文件后刷新**同一个** Taco 再打开：评论线程还在，你逐条核对，满意就点「解决」，不满意就回复继续讨论。

---

各部分能做什么，见 [Taco](../功能/Taco.md)、[Taco Skill](../功能/Taco-Skill.md) 和 [Tacobin](../功能/Tacobin.md)。

> 在这个文档站里，你也可以直接选中文字评论、修改正文，试试看。这是独立版 Taco：没有在线监听和自动保存，「交接改动」只是把内容复制到剪贴板，由你自己交给 Agent。改动只存在浏览器里，刷新页面即恢复原样。
