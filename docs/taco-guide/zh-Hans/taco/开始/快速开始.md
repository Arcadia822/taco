## 1. 让 Agent 安装 Taco

把下面这句话发给你正在用的 Agent（Claude Code、Codex、Cursor 等）：

```text
读取 https://github.com/Arcadia822/taco/blob/main/docs/agent-installation.md ，按其中步骤安装 Taco skill 与 taco-cli（需要时创建目录）；完成后回复 Installed taco. 并简短说明如何生成一份 Taco。
```

Agent 会按安装说明同时安装 `taco` skill 和 `taco-cli`（需要时创建目录），完成后回复 `Installed taco.`：先介绍 Taco 的基本能力，再说明默认使用范围——仅在多文件复杂设计需要人评审拍板，或你主动要求时才使用 Taco；日常探索聊天和简单修复不打包，不会只因为单篇文档长就触发。安装失败时 Agent 会如实报告原因。

## 2. 让 Agent 写一份方案，并生成 Taco

```text
为「订单导出 CSV」写一份设计方案（需求、方案、接口），放在 specs/order-export/，用 Taco 给我评审。
```

Agent 写好 Markdown 后，会把整个目录打包成 `.taco.html` 并在浏览器里打开（可通过 `taco-cli open <file.taco.html> --listen` 启动本机监听）。

## 3. 在浏览器里评审

- 选中一句话，点「评论」，写下具体意见；
- 发现错字或措辞问题，直接在正文里改；
- 流程图节点、代码块的某一行也可以评论；单页 HTML（`.html`）以沙箱只读方式内嵌展示，相关意见写在引用它的 Markdown 文档里。

## 4. 交接给 Agent

点右上角「交接改动」：若 Agent 正在本机监听，未保存改动和未解决评论会直接送达 Agent；没有监听时，改动的 diff 和未解决的评论会复制到剪贴板，粘贴给 Agent 即可。

## 5. 核对第二轮

Agent 改完源文件后刷新**同一个** Taco 再打开：评论线程还在，Agent 只回复处理情况而不会替你解决评论；你逐条核对，满意就点「解决」，不满意就回复继续讨论。

---

各部分能做什么，见 [Taco](../功能/Taco.md)、[Taco Skill](../功能/Taco-Skill.md) 和 [Tacobin](../功能/Tacobin.md)。

> 在这个文档站里，你也可以直接选中文字评论、修改正文，试试看。这是独立版 Taco：没有在线监听和自动保存，「交接改动」只是把内容复制到剪贴板，由你自己交给 Agent。改动只存在浏览器里，刷新页面即恢复原样。
