## 为什么是一个 HTML 文件？

因为浏览器是每个人都有的阅读器。一个 `.taco.html` 双击就能打开，不需要安装软件、注册账号或连接服务器；同时它又只是一个普通文件，可以放进仓库、发邮件、归档。

## 能离线用吗？

Complete 版完全离线，所有编辑器和渲染库都内嵌在文件里。Lite 版需要从公共 CDN 加载编辑器；加载失败时，Markdown 仍然可以按源码编辑。

## 和 git 怎么配合？

仓库里的 Markdown 才是权威版本，正常提交、diff、review。Taco 文件可以和文档放在同一目录一起提交，也可以只在评审时生成。

## 会不会把我的 Markdown 改乱？

不会。Taco 渲染时不会反向格式化你的原文；你没改过的地方，交接时也不会出现在 diff 里。

## Agent 怎么拿到我的评论？

两种方式：点「交接改动」把修改和评论复制给 Agent；或者保存文件，让 Agent 读取 `.taco.html` 里的数据。用 Tacobin 时，Agent 通过 `taco-cli` 获取交接快照。

## 支持多人实时协作吗？

本地 Taco 不支持。需要多人在线评审时用 [Tacobin](../功能/Tacobin.md)：多人可以同时编辑和评论，内容自动保存。

## 支持哪些文件？

Markdown、Mermaid、JSON、YAML（含 OpenAPI 概览）、PNG/SVG 图片和音视频。其他文本文件原样显示为源码。出于安全原因，普通 `.html` 源文件不能打包进 Taco。

## 文件有多大？

Complete 的应用部分约 2.7 MB，Lite 约 180 KB，再加上你的文档本身。

## 必须用 Spec Kit 或检查点吗？

都不需要。它们是可选的；任何 Markdown 目录都可以直接做成 Taco。

## 是开源的吗？

是，MIT 协议，源码在 [github.com/Arcadia822/taco](https://github.com/Arcadia822/taco)。Taco 的灵感与核心代码来自 [Bento](https://github.com/nyblnet/bento)。
