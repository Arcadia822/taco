## 已完成

- **单文件容器**：文档、阅读器、编辑器、评论装进一个 `.taco.html`，离线可用；
- **评审与交接**：划词评论、Mermaid 节点与代码行评论、交接改动；
- **结构化渲染**：YAML 属性表、JSON/YAML 源码编辑、OpenAPI 概览、Mermaid 预览与语法检查；
- **检查点**：阶段依赖图、四种状态、文档要求、未创建占位、项目级模板；
- **Lite shell**：约 180 KB 的联网版本；
- **Tacobin 在线评审**：分享链接、自动保存、显式交接、`taco-cli` 订阅。

## 进行中

### 第二轮审阅体验

人把意见交给 Agent 之后，第二轮需要更快地确认「改了什么、改对没有」：

- **全局讨论列表**：把所有评论线程汇总在一页，按状态和文件筛选；
- **本轮差异**：只看这一轮基线到当前内容的真实变化，点击直接跳到对应位置；
- **人类确认**：Agent 可以说明自己如何处理，但只有人能确认并关闭讨论。

## 规划中

- **文档模板与写作指引**：内置需求、架构、交互设计模板，帮助 Agent 写出层次清楚的文档；
- **真实两轮回归**：用常见的 Agent 宿主完整跑一遍「生成 → 评审 → 交接 → 修改 → 第二轮」，覆盖旧副本、并发修改等情况。
