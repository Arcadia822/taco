## 是什么

Taco 是一个 `.taco.html` 文件：里面装着一组文档、它们的目录结构、一个阅读器和编辑器，以及评论线程。双击就能在浏览器中打开，不需要安装、登录或联网。

一个 Taco 对应一个议题。Agent 把仓库里的文档目录打包成 Taco，人在里面评审，再把结果交还给 Agent。

## 阅读

- **文件树**：保留真实的目录结构。一级目录自动成为分类；也可以用导航清单自定义分组和顺序（本站侧栏就是这样排的）。
- **入口文档**：打开时默认显示的那一篇，在侧栏标有「入口」。
- **搜索**：`⌘K` / `Ctrl+K`，按文件名和全文查找。
- **大纲**：右侧列出当前文档的标题，滚动时自动高亮所在位置。

## 渲染

| 文件类型 | 显示方式 | 本站示例 |
| --- | --- | --- |
| Markdown | 所见即所得编辑；开头的 YAML 显示为属性表 | 每篇 `.md` 顶部的属性 |
| Mermaid（`.mmd` 或 Markdown 中的代码块） | 图表预览 + 源码，可切主题、方向、全屏缩放；语法错误会标出行列 | [系统组件图](../架构/02-系统组件.mmd) |
| JSON / YAML | 语法高亮的源码编辑器 | [数据块示例](../架构/05-数据块示例.json) |
| OpenAPI（JSON / YAML） | 额外提供「概览」视图：接口、参数、响应一目了然 | [Tacobin API](../架构/06-Tacobin-API.yaml) |
| PNG、SVG 图片，音视频 | 内嵌预览 | — |
| 其他文本文件 | 原样显示为源码，不猜测格式 | — |

Taco 不认识的文件也会原样保留，不会在打包或保存时被丢掉。

## 评审

- **划词评论**：选中任意文字即可评论；评论锚定在原文上，原文稍有改动也能重新定位。
- **更细的锚点**：可以评论 Mermaid 图里的某个节点、代码块的某一行。
- **线程**：回复、标记解决或重新打开；可以编辑自己的消息，删除时留下占位，后面的回复不会错位。
- **直接修改**：正文可以直接改，不必写成「建议把 A 改成 B」。

## 交接改动

点右上角「交接改动」，Taco 会把这一轮的结果整理成一段文本复制到剪贴板：

- 每个被修改文件的 diff；
- 所有未解决的评论，带文件路径、被评论的原文和完整讨论；
- 检查点状态的变动。

粘贴给 Agent，它就能逐条处理。也可以保存文件后，把整个 `.taco.html` 交给 Agent 读取。

## 保存

「保存」把改动写回这个 `.taco.html`（浏览器支持时原地写入，否则下载一份）。另有「保存副本」和「解包到文件夹」——后者把文件还原成磁盘上的真实目录。有未保存改动时，关闭页面前会提醒你。

## 检查点（Checkpoints）

当一个议题有多篇文档、需要按阶段推进时，可以给 Taco 加上检查点：

- 用依赖图定义阶段，比如「概览 → 开始 → 功能 / 指南 / 架构 → 路线图」；
- 每篇文档有四种状态：待开始、进行中、已完成、已冻结，阶段状态由文档汇总；
- 每篇文档可以附带「要求」，写给作者（人或 Agent）看；
- 被要求但还没写的文档，会显示为「未创建」。

本站就在用检查点：点侧栏顶部的「检查点」看看。`路线图/下一阶段.md` 就是一篇还没创建、但已经写好要求的文档。详见 [检查点使用指南](../指南/03-检查点.md)。

检查点是可选的；不需要阶段管理时，普通 Taco 就够了。

## Complete 与 Lite

| | Complete | Lite |
| --- | --- | --- |
| 应用体积 | 约 2.7 MB | 约 180 KB |
| 联网 | 完全离线 | 编辑器、高亮、Mermaid 从公共 CDN 加载 |
| 适合 | 发给可能离线的人、长期归档 | 联网评审、放进仓库 |

Lite 的 CDN 不可用时，Markdown 仍可按源码编辑。
