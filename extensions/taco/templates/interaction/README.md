# 交互设计（Interaction Design）模板包

适用于新增或调整用户操作流、需要人确认体验的界面改动，作为中度文档集（`spec.md` + 交互层）或重度文档集的 IxD 层使用。

## 场景定位

- **目标**：在深入接口与存储之前，把角色、入口、主流程与异常、关键状态和体验确认点讲清，让人先拍板「怎么用」。
- **何时用**：有 UI 流程改动、需要原型或体验确认时。无 UI 的改动不要用它，单篇 `spec.md` 的 Given/When/Then 足够。
- **推荐主入口**：`interaction.md`。

## 导航推荐结构

1. **交互说明（Interaction）**：角色与入口、主流程、异常与边界、状态、待决决策项。
2. **图示（Diagrams）**：可复用的 Mermaid 流程或状态图，正文相对路径引用。

## 包含文件

- `template.md`：交互设计通用骨架。
- `bundle.json`：预设分组的最小化交互文档 bundle，含一份 Mermaid 流程图示例。
- `empty.taco.html`：开箱即用的空白交互 Taco，可本地打开查看；它的位置不决定实际 Taco 的输出位置。
